# Library Book Tracking

This context defines the language for a user's personal reading library and the reading statuses they track for its titles.

## Language

**Book**:
A work's edition or format saved in a user's personal reading library for reading-status tracking. It is a reading-list entry, not an owned physical copy; different editions or formats of the same work may be separate Books, and Books may share the same title.
_Avoid_: Physical copy, inventory item

**Reading status**:
A Book's place in the user's reading journey: To read, Currently reading, or Completed.
_Avoid_: Inventory status, lending status

**To read**:
A Book the user plans to read but has not started.

**Currently reading**:
A Book the user has started and has not marked Completed.

**Completed**:
A Book the user considers finished.

**Rereading**:
Reading a previously completed Book again; it remains the same title in the user's personal library.
_Avoid_: A separate Book entry for each reading
